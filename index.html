Connect all devices (one-time setup)

Taaki phone, tablet aur PC teeno pe same time data update ho, ek free Google cloud database (Firebase) se jodna hoga. Isme paisa nahi lagta, aur ye ek baar hi karna hai.

  1. console.firebase.google.com par jao, apne Google account se sign in karo.
  2. "Add project" dabao → naam do (jaise MahraBakery) → Continue → analytics ka option off kar sakte ho → Create project.
  3. Left menu me Build → Firestore Database → Create database → Start in test mode → apna region select karo → Enable.
  4. Top-left gear icon → Project settings → neeche "Your apps" me </> (Web) icon dabao → koi nickname do → Register app.
  5. Jo code dikhega usme const firebaseConfig = { ... } milega — us curly braces ( { } ) ke andar ka poora hissa copy karo aur neeche paste kar do.
Ye ek hi baar karna hai. Jitne bhi device (phone/tab/PC) me ye file khologe, sabme yahi steps follow karke same config paste karna hai — tabhi sab devices ek doosre se jud payenge.
